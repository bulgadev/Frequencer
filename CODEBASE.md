# Frequencer Codebase Organization

## Project Overview
Frequencer is a Go application using the Fyne UI framework for playing audio frequencies. It supports different preset types including single frequencies and binaural beats.

## File Structure

```
Frequencer/
├── main.go                    # Main application entry point (Fyne GUI)
├── main_test.go               # Tests
├── presets.json               # Preset storage (JSON format)
├── go.mod / go.sum            # Go module files
├── pkg/
│   ├── addPreset.go           # UI for adding new presets (forms)
│   ├── models/
│   │   └── presets.go         # Presets struct definition
│   └── utils/
│       ├── runAudio.go        # Audio playback logic
│       ├── loadPreset.go      # Load presets from JSON
│       ├── cacheHandler.go    # In-memory preset cache
│       └── jsonHandler.go     # Save presets to JSON
```

## Key Components

### 1. Data Models (`pkg/models/presets.go`)

**`models.Presets`** - The main preset data structure:
```go
type Presets struct {
    Name        string `json:"Name"`
    Description string `json:"Description"`
    Frequencies string `json:"Frequencies"`  // Frequency value(s) as string
    Type        string `json:"Type"`         // "Default (Frequency)" or "Binaural Beats"
}
```

### 2. Form Generation (`pkg/addPreset.go`)

Structs used for dynamic form generation:
- **`Single_wave`** - Form fields for single frequency presets
- **`Bineural_beats`** - Form fields for binaural beat presets (left/right freq + delta)

### 3. Wave Module Registry (`pkg/utils/runAudio.go`)

Maps wave type names to builder functions:
```go
var waveModules = map[string]func(sampleRate int, freq float64) io.Reader{
    "Default (Frequency)": buildSineWave,
    "Binaural Beats":      buildBinauralBeat,
}
```

### 4. Audio Modules

**SineWave** - Single frequency generator (stereo, same freq both channels)
**BinauralBeat** - Binaural beat generator (different freq per channel) - *stub implementation*

## Data Flow

```
presets.json
     ↓
LoadPresets() → parses JSON → models.Presets
     ↓
CacheIt() → stores in memory (presetCache map)
     ↓
User selects preset from dropdown
     ↓
GetCached() → retrieves models.Presets
     ↓
RunAudio(info, waveType) → plays audio using wave module
```

## FAQ

### Q: Where are presets stored?
**A:** Presets are stored in `presets.json` at the project root. The format is:
```json
{
  "PresetName": {
    "Name": "PresetName",
    "Description": "...",
    "Frequencies": "440",
    "Type": "Default (Frequency)"
  }
}
```

### Q: How do I add a new wave type?
**A:** 
1. Add entry to `waveModules` map in `pkg/utils/runAudio.go`
2. Create a builder function that returns an `io.Reader`
3. Implement the `Read([]byte)` method for your wave generator struct
4. Add form struct in `pkg/addPreset.go` if needed

### Q: How does the cache work?
**A:** The cache is an in-memory `map[string]models.Presets` in `cacheHandler.go`:
- `CacheIt(name, content)` - stores preset
- `GetCached(name)` - retrieves preset
- `ClearCache()` - clears all cached presets

### Q: How do I pass preset data to RunAudio?
**A:** Use `models.Presets` struct:
```go
info, _ := utils.GetCached(name)  // returns models.Presets
utils.RunAudio(info, info.Type)
```

Inside RunAudio, access fields like:
```go
func RunAudio(info models.Presets, waveType string) {
    freq, _ := strconv.ParseFloat(info.Frequencies, 64)
    // info.Name, info.Description, info.Type also available
}
```

### Q: Why does RunAudio use `models.Presets` instead of a map/dict?
**A:** Go is statically typed. Unlike Python dicts, Go uses structs for structured data. `models.Presets` is the struct that matches the JSON preset format. You access fields with dot notation (`info.Frequencies`) instead of key lookup (`info["Frequencies"]`).

### Q: How are binaural beats stored?
**A:** Currently stored with multiple fields in JSON (FrequencieLeft, FrequencieRight, Delta), but the `models.Presets` struct only has a single `Frequencies` string field. This needs to be enhanced to properly support binaural beat parameters.

### Q: What audio library is used?
**A:** [oto](https://github.com/ebitengine/oto) - A low-level audio library for Go. It plays 16-bit PCM audio generated by the wave modules.
